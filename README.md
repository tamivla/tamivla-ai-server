# Tamivla AI Server — Proof of Concept MLOps-сервера

**Цель проекта:** Создание работоспособной альтернативы облачным AI-сервисам под полным контролем. Разработка OpenAI-совместимого сервера для управления локальными языковыми и эмбеддинговыми моделями в среде Windows, когда стандартные инфраструктурные решения (vLLM) были недоступны.

**Статус:** Успешно завершенный Proof of Concept (PoC). Полученный опыт интегрирован в архитектуру последующих production-проектов.

## Достигнутые цели и реализованный функционал

1.  **OpenAI-совместимый API:** Реализация ключевых эндпоинтов (`/v1/chat/completions`, `/v1/embeddings`, `/v1/models`), позволяющая любой системе, работающей с OpenAI API, прозрачно переключиться на локальные модели.
2.  **Динамический менеджер моделей:** Система "горячей" загрузки и выгрузки моделей из оперативной памяти через API для эффективного управления ресурсами.
3.  **Интеграция с экосистемой Hugging Face:** Автоматическое сканирование локального кеша моделей, их валидация и получение детальной информации.
4.  **Кроссплатформенность и работа под Windows:** Стабильная работа сервера в среде, для которой на тот момент не было готовых аналогов с подобным функционалом.
5.  **Контейнеризация:** Упаковка решения в Docker для упрощения развертывания и воспроизводимости.

## Технологический стек

*   **Язык и фреймворк:** Python, FastAPI
*   **Инфраструктура:** Docker
*   **Работа с моделями:** Hugging Face Transformers, собственный кеш моделей
*   **API стандарт:** OpenAI API

## Архитектурная ценность и итоги проекта

Проект был инициирован для решения конкретной инфраструктурной задачи в рамках разработки более крупной системы. Он успешно доказал возможность создания управляемой, изолированной AI-инфраструктуры.

**Практический результат:** Сервер обеспечил работу зависимых проектов на критически важном этапе разработки, позволив проводить тестирование и интеграцию AI-компонентов без зависимости от внешних API и с полным контролем над данными.

**Приобретенный опыт,** впоследствии примененный в production:
*   Глубокое понимание устройства OpenAI-совместимых API.
*   Практические навыки управления жизненным циклом AI-моделей (загрузка, выгрузка, роутинг запросов).
*   Опыт проектирования MLOps-инструментов для изолированных сред.

Развитие данного PoC было приостановлено после появления стабильных и поддерживаемых сторонних решений с аналогичной функциональностью, что является стандартной практикой в инженерии — использовать готовые, проверенные инструменты, когда они становятся доступны.
